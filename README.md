# 天地之中 · 嵩山人文旅行操作系统

一个基于 AI 与大模型技术的文旅撮合与体验平台。深度融合嵩山文化（少林、嵩阳书院、中岳庙、非遗手作等），提供 AI 智能行程匹配、定制行囊表单提交，并包含基于 Canvas 的景区高斯泼溅（3D 点云）交互演示。

## 技术栈
- **前端**：原生 HTML5 / Tailwind CSS / 原生 JavaScript (部署于 GitHub Pages)
- **后端**：Python / FastAPI / LangGraph (部署于 FastAPI Cloud)
- **数据库**：Neon PostgreSQL (Serverless)

## 本地开发与部署
前端直接双击 `index.html` 即可预览。
后端部署请参考 `requirements.txt` 及 FastAPI Cloud 官方文档。
